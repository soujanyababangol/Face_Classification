# Face Classification using MobileNetV3-Small

## Objective

The objective of this project is to classify detected face images into four categories:

1. Neutral Face
2. Face with Mask
3. Face with Sunglasses
4. Face with Mask + Sunglasses

This project focuses on the **face classification module (Part B)**.

## Dataset

The original labelled dataset contains images belonging to the four categories.

The face images were cropped from the original images using the face detection approach developed during Part A.

The cropped face images were then organized into the four class folders.

## Dataset Split

The cropped dataset was divided into:

* Training dataset
* Validation dataset
* Test dataset

The split used was approximately:

* 70% Training
* 15% Validation
* Remaining images for Testing

The final cleaned cropped dataset contained **79 face images**.

## Classification Model

A lightweight **MobileNetV3-Small** model was used for classification.

The pretrained MobileNetV3-Small network was used as the base model, with a classification layer added for the four face categories.

The model was trained using:

* TensorFlow
* Keras
* MobileNetV3-Small
* Image size: 224 × 224
* Batch size: 8
* Epochs: 15

## Training

The model was trained using the training dataset and evaluated during training using the validation dataset.

The validation accuracy reached **100%** during the training run.

## Prediction

After training, new cropped face images were provided through the `image_input` folder.

The trained model predicted the category for each input image.

The prediction results were organized into:

```text
image_classification_output/
├── neutral/
├── mask/
├── sunglasses/
└── mask_sunglasses/
```

A total of **12 new input images** were used for the prediction demonstration, with 3 images from each category. All 12 images were classified correctly.

## Python Files

### train_classifier.py

Splits the cropped face dataset into training, validation, and test datasets.

### train_model.py

Loads the training and validation datasets and trains the MobileNetV3-Small classification model.

### predict_faces.py

Loads the trained classifier and predicts the category of new face images from the `image_input` folder.

## Note

The intermediate cropped dataset, dataset split folders, trained model file, and Part A face detection code are kept outside the GitHub repository for this submission.

The trained model can be generated by running `train_model.py`.
